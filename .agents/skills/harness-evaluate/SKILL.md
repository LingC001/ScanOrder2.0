# harness-evaluate

读取 [工程入口](../../../AGENTS.md) 和 [使用说明](../../../docs/PLANS.md)。

在独立快照中分别植入可验证的文档语义漂移、购物车数量计算缺陷；禁止污染主源码。为缺陷保存初始失败或浏览器复现，执行维护流程修复后再运行同一验证。数量计算缺陷保存修复前后界面证据。使用独立 code-reviewer 评审相对快照的修复。记录来源、命令、退出码、修复补丁及实际评审结果；缺失任何环节均标记未验收。
