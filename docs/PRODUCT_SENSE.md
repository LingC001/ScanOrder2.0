# 产品目标与边界

顾客使用固定账号进入移动端，选择人数、浏览在售菜单、调整购物车、备注下单并查看本人订单状态。商家信息、地址和默认桌号由共享常量提供。

商家在 `/admin` 维护独立分类和商品，执行上下架、归档及恢复，并处理全部订单。新订单从待接单开始，可接单、完成或取消；完成和取消为终态。商品和分类变更不修改历史订单快照。

固定顾客账号用于已确认的单人场景，同一账号跨设备查看上线后创建的订单。功能上线前无归属订单只在商家后台可见。当前订单仍为模拟流程，不包含真实支付、退款、顾客自助注册或员工账号。

产品行为阅读视图见 [产品索引](product-specs/index.md)。
