## 任务级质量度量

每项计划任务在 `verification.md` 记录验收范围、首次整体验收结果及证据、验收后实质性返工轮次、人工干预次数和实际可取得的成本。人工干预指需要人作决定或纠偏的事件，正常的任务授权不计。成本使用可取得的运行时长或费用并标明口径和单位。缺少证据时记为「未采集」，计算汇总时列明有效样本量。

| 指标           | 计算口径                                                  |
| -------------- | --------------------------------------------------------- |
| 首次验收通过率 | 首次整体验收通过数 / 已取得首次验收结果的任务数           |
| 返工率         | 验收后发生实质性返工的任务数 / 已有验收及返工记录的任务数 |
| 人工干预       | 记录每任务需人决策或纠偏的次数及原因                      |
| 成本与交付周期 | 记录可核验的运行时长或费用，以及开始到验收完成的时长      |
