运行步骤以根 README 为入口，接口细节集中在接口说明中，避免重复维护。新增文档后更新本导航；文档中的仓库路径使用相对链接。计划明确区分待办与已完成，验证结果记录实际日期、命令、结果和限制，不将模板内容视为已完成工作。
