| ------ | ------ | ------------------------------------------------------------------------------------ | -------------------------------------------------------- | ---------------------------- | -------------------------------------------------------- |

| TD-004 | P1     | Windows 远端基础验证在生成文档检查失败，见[质量记录](../QUALITY_SCORE.md#实测记录)   | 保留启动诊断，按整改提交复跑与处置                       | 本地诊断已补，待远端验证     | 同一提交 Windows 基础、其余远端作业与汇总检查均通过      |
| TD-005 | P1     | 当前私有仓库套餐缺少主分支保护与必需检查                                             | 先在 PR 人工核对检查和高风险审批，仓库具备能力后开启保护 | 人工流程已定义，自动保护受限 | 失败检查及缺少审批的 PR 无法合入                         |

依据包括 `compose.yaml`、`.env.example`、`apps/api/src/app.ts`、`.github/workflows/harness.yml`、[质量记录](../QUALITY_SCORE.md)和[合入流程](../PLANS.md#主分支合入)。
