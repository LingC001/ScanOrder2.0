# 技术决策记录

使用 ADR（Architecture Decision Record）保存影响长期维护的技术取舍，例如模块边界、数据模型和状态管理。常规实现细节无需独立记录。

复制 [模板](TEMPLATE.md)，以 `NNNN-简短主题.md` 命名，编号从 `0001` 递增，在下表登记。提议不代表已经采纳；只有确定采用的方案才标为“已采纳”。旧决策被替代时保留原记录并链接新决策。

已有方案背景见 [重构计划](../重构计划.md)，当前结构见 [架构说明](../架构说明.md)。
