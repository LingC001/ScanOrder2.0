# 开发指南

## 环境与启动

完整安装、数据库初始化、演示数据导入和生产运行步骤见 [项目 README](../README.md)。使用根 `package.json` 指定的 Node.js 和 pnpm 版本，命令均在仓库根目录执行。

已有本地环境且数据库运行时，执行 `pnpm dev` 启动共享包监听、前端和后端。独立运行应用命令前，先执行 `pnpm --filter @scanorder/contracts build`，因为共享包导出指向构建产物。

本地配置放在根 `.env`，首次从 `.env.example` 复制；已有配置不要覆盖。新增配置时同步维护示例和 README。不要把服务端密钥放入前端环境变量或共享包。

变更依赖时同步更新 `pnpm-lock.yaml`。后端 ESM 本地导入沿用 `.js` 后缀。修改接口、环境变量、迁移或启动方式时同步更新相关文档。

## 常见修改位置

| 需求             | 位置与联动事项                                                                 |
| ---------------- | ------------------------------------------------------------------------------ |
| 页面、交互、样式 | `apps/web/src/pages`、`components.tsx`、`styles.css`；涉及路由时更新 `App.tsx` |
| 购物车行为       | `apps/web/src/cart.ts`、`CartProvider.tsx`，同步相关组件测试                   |
| 接口字段         | `packages/contracts/src/index.ts`、API DTO/服务、Web 调用处和接口说明          |
| 后端模块         | `app.module.ts` 组装；菜品、订单、数据库分别在对应目录的 `*.module.ts`         |
| 商家信息         | 共享包中的 `SHOP` 常量                                                         |
| 数据库结构       | `apps/api/src/database` 中新增迁移，更新实体并注册迁移                         |
| 菜品导入         | `apps/api/src/import`，同步导入规范和相关测试                                  |

## 建议流程

1. 查看工作区改动，阅读相关模块和已有测试。
2. 明确本次行为和验收条件，复杂任务按 [计划与变更流程](PLANS.md) 在 OpenSpec 中维护。
3. 实现改动并更新受影响文档，避免无关格式化和依赖升级。
4. 按 [测试指南](测试指南.md) 执行适用检查，检查 diff 后说明结果。

涉及需要长期解释的技术取舍时，使用 [决策模板](decisions/TEMPLATE.md) 记录原因、替代方案和影响。
