# 常见修改入口

启动命令见 [项目 README](../README.md)，包边界见 [架构地图](../ARCHITECTURE.md)，按改动范围选择验证见 [计划与变更流程](PLANS.md)。

| 要改什么           | 从哪里开始                                                                                                                                                                                                                   |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 页面、交互、样式   | 移动页面与[后台页面](../apps/web/src/pages/admin)位于页面目录，共用[组件](../apps/web/src/components.tsx)和[样式](../apps/web/src/styles.css)。路由由 [App](../apps/web/src/App.tsx) 组装。                                  |
| 购物车             | [状态与计算](../apps/web/src/cart.ts)和 [CartProvider](../apps/web/src/CartProvider.tsx)，同步核对[组件和购物车测试](../apps/web/src/test)。                                                                                 |
| 登录与会话         | [后端身份模块](../apps/api/src/auth)维护商家、顾客会话和登录限流；前端入口及 Cookie 请求见 [App](../apps/web/src/App.tsx) 和 [请求层](../apps/web/src/api.ts)。                                                              |
| 接口字段           | [共享类型](../packages/contracts/src/index.ts)、后端 [categories](../apps/api/src/categories)、[foods](../apps/api/src/foods)／[orders](../apps/api/src/orders) 的 DTO、映射和服务，以及[前端请求](../apps/web/src/api.ts)。 |
| 商家信息和默认桌号 | [共享包的 SHOP 常量](../packages/contracts/src/index.ts)。                                                                                                                                                                   |
| 数据库结构         | 在[迁移目录](../apps/api/src/database/migrations)新增迁移，更新相应实体并在[数据源](../apps/api/src/database/data-source.ts)注册。                                                                                           |
| 菜品导入           | [导入实现](../apps/api/src/import/foods-importer.ts)和[图片与导入规范](product-specs/food-media.md)。                                                                                                                        |

独立启动前端或后端前，先运行 `pnpm --filter @scanorder/contracts build`，共享包导出指向 `dist`。变更依赖时同步更新 `pnpm-lock.yaml`，后端 ESM 本地导入沿用 `.js` 后缀。新增环境变量时同步更新 `.env.example` 和对应说明。
