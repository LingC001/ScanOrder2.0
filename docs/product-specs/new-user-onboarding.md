# 首次点餐流程

这是现有 H5 的用户旅程导航，行为约束以 [菜单](menu.md)、[订单](ordering.md)、[图片与导入](food-media.md) 对应的 OpenSpec 来源为准。

1. 从首页进入，确认默认桌号并选择 1 至 5 位用餐人数；点击“开始点餐”进入菜单。
2. 浏览推荐与分类，预览图片，按菜品 UUID 加入购物车；同名不同 ID 菜品仍分别计数。
3. 在购物车增加、减少或清空菜品。总价使用整数分计算，应等于各单价乘数量之和。
4. 点击“选好了”进入提交页，确认人数、数量和备注。空购物车不能提交，提交中阻止重复点击。
5. 提交失败保留当前内容并显示错误；成功后清空购物车，进入订单列表，再查看订单详情。
6. 订单按下单时的菜名、图片和价格展示快照；“完成”是模拟下单状态，没有真实支付含义。
7. 商家详情提供门店信息；上传页是当前无登录的新增菜品入口，不表示已经具备完整商家后台。

购物车和人数是页面会话内存状态，刷新后重置。初始人数为 1。真实二维码管理、登录、支付和历史订单迁移不在当前产品能力中。

依据：`apps/web/src/App.tsx`、`apps/web/src/pages/Entry.tsx`、`apps/web/src/pages/SubmitOrder.tsx`、`tests/e2e/ordering.spec.ts`。
