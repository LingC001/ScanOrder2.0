# 安全边界

商家后台和顾客接口使用独立 HttpOnly、SameSite 会话 Cookie。服务端校验随机令牌摘要和过期时间，顾客接口按会话账号过滤订单，商家接口要求商家角色。Cookie 使用 `COOKIE_SECURE` 控制 HTTPS 限制，同一来源商家密码连续失败会在短窗口内被限流。

商家口令只以 `scrypt` 哈希配置。`.env.example` 的开发账号口令不能用于生产。固定顾客账号由部署显式开启，所有使用该账号的设备会看到同一订单集，必须结合实际运营场景确认开放范围。

菜品图片只由已登录商家在后台新增或替换。上传检查真实图片类型与大小，保存失败清理本次文件；历史订单图片文件保留。导入预检输入，数据库参数化查询和 DTO 校验用于限制输入。

开发与测试凭据仅用于本机隔离环境。环境文件、上传数据和运行状态不提交 Git；快照排除实际 .env、上传目录与运行产物。日志和追踪不得包含数据库凭据、订单备注、请求正文或授权头。

Grafana 与 OTLP 仅发布到回环地址，状态查询不输出管理口令。清理依赖资源归属，不按通用进程名终止其他服务。镜像按摘要固定，依赖按锁文件安装；新增安装脚本先核实用途。

依据：`apps/api/src/storage/image-storage.service.ts`、`apps/api/src/telemetry/logger.ts`、`scripts/harness/runtime-worker.mjs`。
