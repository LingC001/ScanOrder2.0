ScanOrder 当前设计系统参考

依据为 apps/web/src/styles.css、apps/web/src/pages/customer/CustomerComponents.tsx 和 apps/web/src/shared/Modal.tsx；不是新引入的 UI 产品。

品牌主色：#fc9904；强调色：#fd6836。
页面背景：#eeedef；基础文字：#333。
字体依次使用 Helvetica Neue、Helvetica、Arial、Microsoft Yahei 和系统 sans-serif。
应用根节点占满视口。移动点餐使用最大 480px、高度 100dvh 的 customer-root 并在宽屏居中；商家后台使用全宽响应式布局，桌面显示侧栏，窄屏使用顶部导航。
基础控件继承字体，禁用按钮透明度 0.5、使用默认指针；键盘焦点使用 2px 强调色轮廓和 3px 偏移。
主要按钮使用 primary-button 的 Tailwind 类，最小高度 min-h-11，圆角 rounded-md。
图标按钮使用 h-9、w-9 的圆形点击区域。模态层与购物车必须能关闭，底栏不能遮挡内容。

移动视觉验收宽度为 375、390、430 像素，商家后台同时检查窄屏和桌面布局。自动截图和无横向溢出检查之外，设计稿还原需要使用内置浏览器对照原稿。
