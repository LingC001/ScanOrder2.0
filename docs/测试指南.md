# 测试指南

以下命令均从仓库根目录执行；以根 [package.json](../package.json) 中的脚本为准。

## 检查与测试分层

| 命令                    | 用途与适用改动                                         |
| ----------------------- | ------------------------------------------------------ |
| `pnpm typecheck`        | 应用、共享包和测试的类型检查                           |
| `pnpm lint`             | ESLint 检查，要求无警告                                |
| `pnpm format:check`     | 全仓 Prettier 检查                                     |
| `pnpm test`             | 共享金额工具、后端单元测试、前端组件和购物车测试       |
| `pnpm test:integration` | 真实 PostgreSQL 上的 API、订单事务、图片上传和导入行为 |
| `pnpm test:e2e`         | 生产构建上的浏览器流程与移动端布局                     |
| `pnpm build`            | 验证共享包、API 和 Web 的生产构建                      |

只修改文档时，可以执行 `pnpm exec prettier --check AGENTS.md README.md "docs/**/*.md"`，或将参数缩小到本次修改的文件，再检查相对链接和命令是否有效。已有无关格式问题应单独报告，不顺手全仓重写。

## 测试入口

- 共享包：`packages/contracts/test`，Node.js test runner。
- 后端：`apps/api/test/unit.test.ts`、`integration.test.ts`，Node.js test runner。
- 前端：`apps/web/src/test`，Vitest 与 Testing Library。
- 浏览器：`tests/e2e/ordering.spec.ts`，Playwright。

集成与 E2E 命令会先构建，使用 `scripts/with-postgres.mjs` 启动隔离的临时 PostgreSQL，执行迁移并清理。不要将这些测试手动改接开发数据库。

首次执行浏览器测试前运行 `pnpm exec playwright install chromium`。浏览器报告写入 `playwright-report`，截图和其他产物写入 `test-results`；这些目录不提交。页面布局改动需检查 375、390、430 像素宽度下的滚动、底部操作区和弹窗。
