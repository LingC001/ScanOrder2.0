# agent-observability 规范

## Purpose

让 Agent 能结合浏览器操作、服务日志、请求指标和数据库追踪定位故障，并以实例和请求标识关联证据，支持可重复的性能断言，同时避免把凭据、订单备注等敏感内容写入诊断数据。

## Requirements

### Requirement: 请求证据关联

系统 SHALL 采集结构化日志、请求指标及 HTTP 和数据库追踪，使用实例和请求标识关联。

#### Scenario: 真实下单诊断

- **WHEN** 在隔离实例中成功创建订单
- **THEN** 能够查询关联日志、请求计数和包含数据库操作的追踪

### Requirement: 隐私与访问边界

诊断数据 SHALL 排除凭据、请求正文和备注，观测端口仅绑定本机回环地址。

#### Scenario: 包含敏感输入

- **WHEN** 用户提交带有备注的订单
- **THEN** 查询结果包含操作结果而不包含备注内容或数据库密码

### Requirement: 就绪与性能断言

Harness 模式 SHALL 提供存活和数据库就绪检查，并支持对实测指标执行阈值断言。

#### Scenario: 就绪失败

- **WHEN** 数据库不能查询
- **THEN** 就绪检查返回失败状态而非成功
